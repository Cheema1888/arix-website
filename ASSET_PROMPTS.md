# Arbots X — Optional Asset Prompts

The website ships with an animated, code-native X robot so none of these assets block deployment. These prompts are for future visual upgrades while keeping one consistent robot identity.

## 1. Hero Robot Render

- **Asset name:** `arbots-x-hero-render`
- **Used in:** Product-page hero, centered inside the glowing X
- **Aspect ratio:** 4:5 transparent cutout or black studio background
- **Style:** Premium cinematic product render
- **Prompt:**

  > A single small premium AI companion robot named X, desktop scale, rounded matte graphite shell, glossy black face screen, two expressive electric-cyan eyes, subtle side sensors, compact stable base, friendly but sophisticated proportions, photographed as a high-end robotics product in a deep black studio with cool cyan rim lighting and a faint violet edge light. Front three-quarter view, centered, full robot visible, emotionally warm and intelligent, precise industrial design, realistic materials, no text, no logo, no other robots, no human, no clutter, no watermark. Preserve this exact robot identity for every future Arbots X image.

- **Asset name:** `arbots-x-expression-states`

Preserve the identical graphite head, glossy face screen, cyan eye style, camera angle, lighting, scale, and background in every state. Change only the eyes, mouth light, and subtle head pose. Premium black studio, electric-cyan glow, restrained violet rim, no text, no extra objects, no redesign, no watermark.
